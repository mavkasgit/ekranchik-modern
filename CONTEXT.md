# Ekranchik Modern

Клиент-серверный комплекс для отображения промышленного дашборда гальванической линии на выделенных мониторах. Бэкенд собирает данные из файла учёта (Excel) и по протоколу OPC UA, фронтенд показывает текущее состояние линии.

## Language

**Подвес**:
Единица учёта на линии — одна строка в листе «Подвесы» книги учёта. Характеризуется номером, датой/временем загрузки, профилем, цветом, количеством ламелей и связанным заказом (КПЗ).
_Avoid_: хэнгер, hanger (в коде используется только как имя типа данных)

**Смена**:
Период работы операторов линии (1-я, 2-я, 3-я). Атрибут строки-подвеса в листе «Подвесы».
_Avoid_: shift

**Фамилия**:
Фамилия оператора, который загрузил конкретный подвес. Заполняется вручную в Excel, в колонке сразу после «Смена». Не отображается и не передаётся приложением.
_Avoid_: оператор (неоднозначно), ответственный

**КПЗ**:
Номер заказа (клиентского заказа на производство), к которому относится подвес.
_Avoid_: kpz (только как имя поля в коде)

**Ламели**:
Количество ламелей (отдельных элементов) на подвесе.

**Вид материалов**:
Тип материала подвеса (например, «Пороги», «Клюшки (растрав)»).
_Avoid_: тип материала (в коде поле называется material_type)

**Годность подвеса**:
Отметка о качестве подвеса; значение «Брак» помечает строку как дефектную.
_Avoid_: defect (только как имя поля в коде)

**Заказчик**:
Клиент, для которого производится заказ.
_Avoid_: клиент (только как имя поля в коде)

**Профиль**:
Профиль (артикул) изделия на подвесе. Может содержать несколько артикулов через `+` или `/`.

**Линия**:
Гальваническая линия целиком — набор ванн, через которые последовательно проходит подвес. Текущее состояние линии приходит с OPC UA.
_Avoid_: конвейер

**Ванна**:
Одна позиция линии со своим номером; подвес занимает ванну на время обработки.
_Avoid_: bath (только как имя поля в коде)

**Контрольная ванна**:
Ванна 34 — точка, где подвес сходит с линии (выгрузка).
_Avoid_: ванна выгрузки, контрольная точка

**Киоск**:
Режим работы приложения-экранчика на выделенном мониторе: полноэкранное окно с дашбордом без собственного сервера — открывает готовый URL. В коде exe исторически называется «launcher».
_Avoid_: лаунчер (в речи — только киоск)

**Полный режим**:
Режим, при котором серверная часть (бэкенд с данными и веб-интерфейсом) и экран киоска работают на одной машине без Docker в одном приложении: трей, окно настроек и полноэкранный дашборд — один процесс, одна иконка в трее. Пользователь портов и статусов не видит.

**Тип установки**:
Выбор при установке: «Только киоск» или «Полный пакет». Один и тот же установщик, режим можно сменить повторной установкой.
