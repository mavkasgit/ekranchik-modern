# Ekranchik Modern

Клиент-серверный комплекс для отображения промышленного дашборда гальванической линии на выделенных мониторах. Бэкенд собирает данные из файла учёта (Excel) и по протоколу OPC UA, фронтенд показывает текущее состояние линии.

## Language

**Подвес**:
Физическая единица с номером, которая ходит по линии. Номер повторяется от смены к смене, поэтому подвес не идентифицирует один проход по линии.
_Avoid_: хэнгер, hanger (в коде используется только как имя типа данных)

**Проход**:
Одно прохождение подвеса по линии, которое видит монитор: номер прохода, момент первого замера, ванна первого замера, путь по ваннам с временами.
_Avoid_: цикл, cycle (только как имя поля в коде), прогон

**Строка книги учёта**:
Строка листа «Подвесы» книги учёта КПЗ (Excel), которую заполняет человек: номер подвеса, дата и время загрузки, профиль, цвет, ламели, КПЗ, смена, годность. Монитор её не создаёт.
_Avoid_: учётная запись, запись

**Выгрузка**:
Выход подвеса с линии — его разгрузка в контрольной ванне.
_Avoid_: сход

**Сопоставление**:
Установление соответствия прохода строке книги учёта — по номеру подвеса и близости момента первого замера ко времени загрузки в строке.
_Avoid_: подбор, matching (только как имя модуля и функции в коде)

**Смена**:
Период работы операторов линии (1-я, 2-я, 3-я). Атрибут строки книги учёта.
_Avoid_: shift

**Фамилия**:
Фамилия оператора, который загрузил конкретный подвес. Заполняется вручную в Excel, в колонке сразу после «Смена». Не отображается и не передаётся приложением.
_Avoid_: оператор (неоднозначно), ответственный

**КПЗ**:
Номер заказа (клиентского заказа на производство), к которому относится подвес.
_Avoid_: kpz (только как имя поля в коде)

**Ламели**:
Количество ламелей (отдельных элементов) на подвесе.

**Вид материалов**:
Тип материала подвеса (например, «Пороги», «Клюшки (растрав)»).
_Avoid_: тип материала (в коде поле называется material_type)

**Годность подвеса**:
Отметка о качестве подвеса; значение «Брак» помечает строку как дефектную.
_Avoid_: defect (только как имя поля в коде)

**Заказчик**:
Клиент, для которого производится заказ.
_Avoid_: клиент (только как имя поля в коде)

**Профиль**:
Профиль (артикул) изделия на подвесе. Может содержать несколько артикулов через `+` или `/`.

**Обработка Профиля**:
Вид обработки, записанный в одной ячейке с артикулом Профиля: «окно», «греб», «сверло», «фреза», «паз», «отв». В книге учёта «гребенка» — та же обработка, что «греб».
_Avoid_: просто «обработка» (так называют время обработки в ванне), операция (в коде — processing)

**Линия**:
Гальваническая линия целиком — набор ванн, через которые последовательно проходит подвес. Текущее состояние линии приходит с OPC UA.
_Avoid_: конвейер

**Ванна**:
Одна позиция линии со своим номером; подвес занимает ванну на время обработки.
_Avoid_: bath (только как имя поля в коде)

**Контрольная ванна**:
Ванна 34 — точка, где подвес сходит с линии (выгрузка).
_Avoid_: ванна выгрузки, контрольная точка

**Киоск**:
Отдельное приложение-экранчик `Ekranchik.exe` на выделенном мониторе:
полноэкранное окно с дашбордом без собственного сервера — открывает готовый
URL, взятый из своих настроек. Своего бэкенда у него нет и не было. В коде
проект исторически называется «launcher».
_Avoid_: лаунчер (в речи — только киоск)

**Сервер**:
Фоновое приложение `EkranchikServer.exe`: встроенный Python + uvicorn с
раздачей собранного веб-интерфейса, чтение книги учёта Excel по сети, OPC
UA, трей с «Настройками» и «Выходом», окно настроек, автозапуск. Экрана
киоска у него нет. Раньше это был «полный режим» — merged-приложение вместе с
экраном в одном процессе (ADR 0002, заменено ADR 0004).
_Avoid_: All-in-One, merged-приложение, полный пакет


**Журнал подвесов**:
Файл `hanger-passes-YYYY-MM-DD.jsonl` с историей проходов по линии: одна
строка — один проход с путём по ваннам, подбором строки книги и вердиктом
сопоставления. Пишет приложение само, одинаково в dev, контейнере и exe, и
лежит рядом с базой данных, а не в логах контейнера. Показывается в
разделе «OPC UA → Hanger Tracking».
_Avoid_: лог (у приложения есть ещё и служебные логи), выгрузка (это
разгрузка подвеса)

**Времена прохода**:
Четыре момента, по которым проход виден целиком: вход и выход по линии
(их видит монитор) плюс вход и выход по книге учёта. В книге времени
выхода НЕТ — она ведёт только фактический момент загрузки в линию, —
поэтому хранятся три момента, а четвёртое поле остаётся пустым. В
журнале подвесов они лежат под именами `line_entry_at`, `line_exit_at`,
`book_entry_at`, `book_exit_at`.
_Avoid_: время входа (непонятно, по линии или по книге)

**Адрес для экранов**:
Адрес дашборда, который сервер показывает в окне настроек
(`http://<ip-машины>:8083`) и который оператор вводит в настройках экрана
киоска. При снятой галке «Доступ из локальной сети» адрес недоступен с
других компьютеров.

**Тип установки**:
Выбор при установке: «Только киоск (экран на отдельном компьютере)»,
«Сервер: фоновое приложение» или «Оба на одной машине» (выборочная
установка). Один и тот же установщик, состав можно сменить повторной
установкой; снятие галки удаляет только своё приложение, каталог данных,
настройки и логи не трогает.
