## Допущения

- Ветка названа по дате старта (`night/2026-11-08`); к концу работы календарь перешёл на 09.11.2026. Имя ветки не менял.
- `parse_excel_time` для невалидного времени (`25:00`, `18:61`) возвращает `(0,0,0)` по существующему контракту «битое → нули». В журнале такое время может выглядеть как полночь; это осознанно меньшая проблема, чем остановка журнала. Чтобы отличать «нет времени» от «00:00», нужна отдельная правка контракта.
- Имена профилей с `/` считаю допустимыми (это записано в `CONTEXT.md`); в имени файла заменяю разделители на `_`, а не транслитерирую кириллицу, иначе перестали бы находиться уже лежащие фото.
- `updated_at` — достаточный cache-buster: он меняется при загрузке, замене и удалении фото; для этого повторная загрузка теперь явно его двигает.
- Публичный API: `baths_visited` в журнале стал nullable только для чтения старых записей; новые пишутся как `[]`. `free` теперь возвращает реальное значение PLC — это исправление бага, а не смена контракта.
- Рабочий стенд запущен в реальном режиме (PLC + сетевая книга), не в симуляции; перезапуск выполнен по инструкции `AGENTS.md` через Orca.
