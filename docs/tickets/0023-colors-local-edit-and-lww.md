# 0023 — Локальная правка цвета и правило «новее — правильнее»

Спека: [0003](../specs/0003-color-dictionary-and-third-party.md).
Зависит от: 0022. Блокирует: T-381.

## Задача

Администратор может поправить название или hex цвета прямо в Экранчике, не
дожидаясь KTM. Правка запоминает время и переживает синк, если она новее
правки в KTM. Создавать и удалять цвета через API нельзя: список пополняется
засевом и синком.

## Объём

### API

- `PATCH /api/colors/{id}` принимает `name` и/или `hex`; оба необязательные,
  пустой запрос — 422.
- Успех: 200 с обновлённой строкой. Нет цвета — 404. Некорректный hex — 422.
- Успешная правка ставит `updated_at` в текущее UTC-время и `source=local`.
- `code` и `operation_code` через этот маршрут не меняются: это ключи
  синхронизации, а не подпись.
- Создание, удаление и изменение `source` вручную отсутствуют.

### Синхронизация

- Синк сопоставляет строки по `operation_code`; если его нет — по
  нормализованному названию (регистр, пробелы, дефисы, подчёркивания).
- Поля `name`, `hex`, `code` обновляются, только если `updated_at` из KTM
  строго новее локального. При равенстве остаётся локальная строка.
- Строки `source=local`, которых нет в KTM, не удаляются и не помечаются.
- Синк не трогает `notes`-подобных полей: у цвета их нет.
- Время хранится и сравнивается в UTC; сравнение — по дате, не по строке.

### Тесты

- `PATCH` меняет `name`, `hex`, `updated_at`, `source`.
- `PATCH` не меняет `code` и `operation_code`.
- 404 на несуществующий id, 422 на пустое тело и плохой hex.
- Синк: локальная правка новее — остаётся; KTM новее — перекрывает; равное
  время — остаётся локальная.
- Локальная строка без пары в KTM переживает синк.

## Приёмка

1. Правка названия `C32` видна в `GET /api/colors` и в панели.
2. После синка с более старой меткой KTM правка на месте.
3. После синка с более новой меткой KTM значение обновилось.
4. Локальный `RG` не исчез после синка.
