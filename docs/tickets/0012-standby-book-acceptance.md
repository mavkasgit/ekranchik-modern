# 0012 — Приёмка режима запасной книги

Спека: [0001](../specs/0001-standby-book.md).
Зависит от: 0008, 0009, 0010, 0011.

## Задача

Проверить изменение целиком и убедиться, что стенд живой.

## Чек-лист

- `mise run check` — зелёный (tsc, oxlint, oxfmt, knip, ruff, shellcheck,
  betterleaks, hadolint).
- `mise run test` — backend pytest и frontend vitest зелёные.
- `npm --prefix frontend run build` — собирается.
- Dev-стенд перезапущен в соседнем терминале Orca и отвечает:
  `http://127.0.0.1:8013/health` и `http://127.0.0.1:5173/`.
- Ручной сценарий на стенде (если доступен файл): задать основную и запасную
  роль, убедиться, что статус показывает роль и что без запасной режим
  выключен.
- Критерии приёмки спеки 1–7 выполнены.

## Вне объёма

E2E-тест на переключение книг не добавляется: он требует двух живых книг с
управляемым ростом строк, а правило покрыто unit-тестами.
