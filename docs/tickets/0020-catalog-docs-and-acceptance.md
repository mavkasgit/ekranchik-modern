# 0020 — Каталог: документация, глоссарий и приёмка

Спека: [0002](../specs/0002-catalog.md). Закрывает все предыдущие тикеты.

## Задача

Зафиксировать термины и правила витрины в `CONTEXT.md`, привести ссылки в
документации и пройти приёмку спеки.

## Объём

### Глоссарий

`CONTEXT.md`, раздел Language:

- **Артикул** — единица каталога; в UI каталога пишем «Артикул», в коде и
  книге — «профиль»;
- **Наименование** — читаемое описание артикула из каталога-источника,
  не путать с примечанием;
- **Примечание** — локальные данные киоска, не синхронизируются;
- **Витрина** — режим каталога, в котором поля артикула только читаются;
- у существующего термина «Профиль» — уточнение про UI-имя «Артикул».

Новые термины формулировать без реализации: `CONTEXT.md` — словарь, а не
спека.

### Документация

- `README.md` — раздел про каталог: витрина, что читается и что
  редактируется, где искать примечания;
- `docs/specs/0002-catalog.md` — статус «принята» и ссылки на тикеты после
  реализации;
- `docs/adr/README.md` — строка 0010 уже есть;
- проверить, что в пользовательских текстах нет источника данных
  (`rg -n "KTM|синхрон|источник|обновлено из" frontend/src`).

### Приёмка

Пройти [критерии приёмки спеки](../specs/0002-catalog.md#критерии-приёмки)
по пунктам, с отметкой в этом тикете после проверки:

1. нет кнопок создания, правки, удаления, загрузки фото, кропа, ZIP;
2. поля карточки только читаются; примечание сохраняется и переживает
   перезагрузку;
3. поиск, сортировка и фильтры работают на клиенте, общие для плитки и
   таблицы;
4. фото вписано на 1920×1080, 1366×768, 1024×600, 900×500, 390×844; зум,
   панорама, Esc, копирование и скачивание;
5. API без `usage_count`, write-маршруты отвечают 404/405,
   `PATCH /notes` — 200/404/422;
6. `PATCH /notes` не трогает остальные поля; синк не трогает примечание;
7. UI без слов об источнике данных;
8. `mise run check` и `mise run test` зелёные, e2e каталога проходит;
9. синк (T-377) переносит наименование и не фильтрует по активности.

## Проверка

1. `mise run check`, `mise run test`, `npm run test:e2e`.
2. Перезапустить dev-стенд в соседнем терминале Orca и пройти чек-лист руками.
3. Приложить в тикет список проверенных вьюпортов и результат `rg` по
   запрещённым словам.
