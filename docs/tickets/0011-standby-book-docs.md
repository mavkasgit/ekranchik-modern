# 0011 — Документация: глоссарий и README

Спека: [0001](../specs/0001-standby-book.md). Решение: [ADR 0009](../adr/0009-standby-book-follows-growing-rows.md).
Зависит от: 0008, 0009 (описание должно совпадать с кодом).

## Задача

Записать термины и поведение так, чтобы новый читатель не путал запасную
книгу с резервной копией и не «чинил» автономное переключение.

## Объём

- `CONTEXT.md`, раздел «Language»: термины **«Основная книга учёта»** и
  **«Запасная книга учёта»**; явная оговорка, что это не «Резервная копия
  книги учёта». Формулировки — только доменные, без деталей реализации
  (порог 30 минут и поля API — в ADR/спеке).
- `README.md`: раздел рядом с «Автобэкап книги учёта» — что делает режим,
  как включить (две роли в «Ввести путь»), что видит оператор, где смотреть
  журнал (`book_name`/`book_path`), какие ограничения (30 минут наблюдения
  после рестарта, автобэкап снимает активную книгу в папку с именем этой
  книги в том же корне).
- Ссылки: спека ↔ ADR ↔ тикеты.

## Проверка

`mise run check` по markdown (oxfmt) — без изменений форматирования;
термины в README и `CONTEXT.md` совпадают.
