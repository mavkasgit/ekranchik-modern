# 0013 — Диалог книг: без обрезки, с путём оператора и без баннера на дашборде

Спека: [0001](../specs/0001-standby-book.md). Предшествует: [0010](0010-standby-book-ui.md)
(в части баннера — отменяет его).

## Задача

Три жалобы оператора после первого дня работы с ролями книг:

1. Диалог «Книги учёта» обрезается справа: длинный путь запасной книги
   выталкивает содержимое за край окна, кнопка «Сохранить» уходит под обрез.
2. Введённый путь `\\ktm-disk\Оператор\Учет КПЗ 2026.xlsm` показывается как
   `/app/excel/Учет КПЗ 2026.xlsm`. Пути контейнера на машине оператора нет:
   по такой строке нельзя понять, ту ли книгу он выбрал.
3. Баннер «Читается запасная книга…» на дашборде висит и в полноэкранном
   киоске. Служебное пояснение должно быть в инфо-меню, а не на экране линии.

## Объём

### Обрезка диалога

`frontend/src/pages/Dashboard.tsx`, `DialogContent` и его прямые дети.

Причина — не `max-w-2xl`, а грид-трек Radix-диалога: ширина трека считается
по `min-content` детей, а подпись «запасная: …» в подвале не переносится и
тянула трек на 724 px при окне 672 px. Дальше `overflow-hidden` просто
отрезал правый край.

- `min-w-0` у прямых детей диалога (шапка, блок «Читается сейчас», сетка
  книг, ошибка, подвал) и у секций книг: трек больше не растягивается.
- Подпись в подвале — `flex-1 min-w-0 truncate`, кнопки — `shrink-0`: текст
  сокращается многоточием, кнопки остаются на месте.
- `max-h-[92dvh]` + `overflow-y-auto` у диалога: на низком экране окно
  прокручивается, а не уезжает за границу.

### Путь оператора вместо пути сервера

`backend/app/api/routes/dashboard.py`, `backend/app/services/excel_service.py`.

Сервер по-прежнему читает книгу по своему пути (`/app/excel/…` в контейнере,
UNC на dev-хосте): именно он открывается. Но путь для показа хранится
отдельно — так, как его набрал оператор.

- `_resolve_book_input` (бывший `_resolve_book_file`) возвращает пару:
  путь сервера и ввод оператора, если книгу нашли только после перевода в
  смонтированный каталог. Путь, который открывается как есть, показывается
  разрешённым — относительное имя и короткое имя Windows не должны выглядеть
  иначе, чем файл на диске.
- `ExcelService` хранит `main_entered`/`reserve_entered` рядом с ролями, в том
  же файле выбора (`EXCEL_ACTIVE_FILE_NAME`); старые записи без этих полей
  читаются и показывают путь сервера.
- Ввод оператора отдают все поверхности: строка статуса
  (`file_path`, `main_file_path`, `reserve_file_path`), `GET /excel/books`,
  ответ `POST /excel/books`, `/settings` (страница OPC UA), история «Последние».
- История путей помнит ввод, а не путь сервера: чипы снова узнаваемы.

### Баннер запасной книги

- Из дашборда баннер убран целиком (и в обычном окне, и в киоске): метка роли
  в строке статуса остаётся, ручного выбора книги по-прежнему нет.
- Причина перехода («Читается сейчас: Запасная» + `standby_reason`) видна в
  инфо-меню — `frontend/src/pages/OPCUAPage.tsx`, блок «Книга учёта».

## Тесты

- `backend/tests/integration/test_excel_books_api.py` — ввод UNC отдаётся в
  `main`/`active`/`main_file_path`, а в файле выбора лежит путь сервера и ввод
  оператора отдельно; история помнит ввод.
- `backend/tests/integration/test_excel_select_api.py` — ответ `select` и
  `/status/file` называют путь оператора для UNC и `Z:`.
- `backend/tests/unit/test_resolve_book_file.py` — пара «путь сервера + ввод»
  для существующего и переведённого пути.
- `frontend`: `tsc`, `vitest`, `oxlint`, `oxfmt`; ручная проверка диалога на
  1024, 1280 и 1920 px (нет элементов за краем окна).

## Проверка

1. `mise run check` и `mise run test`.
2. Перезапустить dev-стенд в соседнем терминале Orca (uvicorn без `--reload`).
3. В диалоге книг ввести длинный путь запасной книги — правый край и кнопка
   «Сохранить» на месте.
4. Сохранить UNC-путь и убедиться, что строка статуса, диалог и OPC UA →
   Settings показывают ввод оператора, а книга читается.
