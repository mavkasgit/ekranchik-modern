# 0025 — ADR, термины и приёмка справочника цветов

Спека: [0003](../specs/0003-color-dictionary-and-third-party.md).
Зависит от: 0023, 0024, T-381.

## Задача

Зафиксировать решение о двух владельцах справочника цветов и проверить его на
живом стенде. Без документов следующая правка снова сделает цвета локальной
константой или, наоборот, отдаст их только KTM.

## Объём

### ADR

Новый `docs/adr/0013-color-dictionary-owner.md`:

- контекст: цвета — операции анодирования в KTM; в Экранчике они нужны для
  отображения; старые названия и новые коды живут вместе;
- решение: KTM — источник, Экранчик — локальная копия; синк по правилу
  «новее — правильнее»; локальные строки не удаляются; панель показывает код;
- альтернативы: зашитый список (отвергнут — устаревает), только KTM
  (отвергнут — нельзя отвязаться и дозаполнить), только локальный список
  (отвергнут — два владельца без синка);
- последствия: справочник цветов — второе локально редактируемое поле после
  примечания; `updated_at` обязателен; старые операции не переименовываются;
  hex с веера справочный.

### Термины

В `CONTEXT.md` добавить:

- **Цвет** — покрытие, которое наносится на анодировании; в книге пишется
  словом или кодом.
- **Код цвета** — `C31`; канон латиницей, кириллица `С31` принимается.
- **Название покрытия** — «Тёмная шампань»; не путать с кодом.
- **Операция анодирования** — операция участка `ANODIZING`; для новых цветов
  её код совпадает с кодом цвета, для старых остаётся `ANOD_0x`.
- **Сторонний заказ** — материал заказчика, который завод только анодирует;
  отметка на продукте, без отдельной сущности.
- **Комплект урн** — корпус и крышка; на подвес 4 комплекта, итого 8 предметов.

### Спека 0002 и ADR 0010

Добавить явное исключение: справочник цветов — локально редактируемый, в
отличие от артикула. Правило «артикул приходит из KTM» не меняется.

### Проверка

- `mise run check` зелёный.
- На dev-стенде: строка `С32` показывает `C32` и тёмную шампань; «Все цвета»
  показывает полный справочник; ручная правка названия переживает синк;
  карточка `урны` открывается из строки книги.
- Проверить, что старые строки (`серебро`, `черный`, `шампань`) не изменили
  вид.

## Приёмка

1. ADR 0013 и термины на месте, ссылки из спеки 0003 работают.
2. Спека 0002 и ADR 0010 не противоречат новому исключению.
3. `mise run check` зелёный.
4. Ручная проверка на стенде пройдена и описана в PR.
