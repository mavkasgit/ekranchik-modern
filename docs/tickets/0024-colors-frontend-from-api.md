# 0024 — Панель берёт цвета из API и показывает код

Спека: [0003](../specs/0003-color-dictionary-and-third-party.md).
Зависит от: 0022. Блокирует: 0025.

## Задача

Убрать зашитый `COLOR_CATALOG` из фронтенда. Справочник цветов приходит из
`GET /api/colors` и используется дашбордом, прогнозом ванн и режимом «Все
цвета». В ячейке цвета дашборда оператор видит код (`C32`), название — в
подсказке. Неизвестный цвет по-прежнему серый.

## Объём

### Справочник

- Хук `useColors` (TanStack Query) с долгим `staleTime`: справочник меняется
  редко, лишние запросы не нужны.
- Пока справочник грузится или если запрос упал, панель не ломается: цвета
  показываются как неизвестные (серый, аббревиатура). Экран не блокируется.
- Тип `ColorSpec` расширяется полем `code`; `COLOR_CATALOG` удаляется.
- Чистые функции `colorCode`, `colorName`, `colorHex`, `colorAbbreviation`
  принимают справочник первым аргументом. `colorCellStyle` не меняется.

### Сопоставление

- Сначала точное совпадение по коду, затем по названию; затем вхождение
  названия, как сейчас.
- Код сравнивается без учёта регистра, пробелов, дефисов и подчёркиваний;
  кириллическая `С` и латинская `C` считаются одной буквой. Это нужно, чтобы
  `С32` из книги находил `C32` из справочника.
- Названия сравниваются как сейчас: регистр, пробелы, дефисы и подчёркивания
  не различаются. `шампань` остаётся за старым названием, `C31`/`C32` — за
  новыми кодами.
- Если у найденного цвета нет кода, `colorCode` возвращает текущую
  аббревиатуру.

### Экран

- Дашборд: в ячейке цвета — `colorCode`; `title` — `colorName`.
- `BathForecastTable`: аббревиатура остаётся, название — в подсказке.
- «Все цвета» и случайный цвет в режимах витрины берут список из справочника
  API. Строк столько, сколько цветов в справочнике.
- Никаких бейджей происхождения и пометок «локальный»/«из KTM» нет.

### Тесты

- `color.test.ts`: `С32` и `C32` дают один цвет; `C41` — медь; `C44` —
  тёмная медь; `шампань` не перехватывается светлой/тёмной; неизвестный цвет
  остаётся серым; `RG`/`RB`/`RST` находятся.
- `simRows.test.ts`: режим цветов даёт по строке на каждый цвет фикстуры;
  случайный цвет — из фикстуры; тесты не зависят от длины реального
  справочника.
- Тест дашборда (если есть подходящий) или ручная проверка: ячейка показывает
  код, подсказка — название.

## Приёмка

1. Строка книги с `С32` показывает `C32` и тёмную шампань.
2. Строка с `серебро` показывает аббревиатуру, как раньше.
3. Неизвестный цвет серый, с аббревиатурой.
4. «Все цвета» показывает все цвета из `GET /api/colors`.
5. В коде фронтенда нет `COLOR_CATALOG` и зашитого списка цветов.
