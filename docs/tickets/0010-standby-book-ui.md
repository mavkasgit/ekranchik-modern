# 0010 — Экран: роли в диалоге пути, метка и баннер

Спека: [0001](../specs/0001-standby-book.md). Решение: [ADR 0009](../adr/0009-standby-book-follows-growing-rows.md).
Зависит от: 0008 (контракт API зафиксирован спекой).

## Задача

Оператор задаёт две книги и видит, какую книгу читает дашборд сейчас.

## Объём

Файлы: `frontend/src/pages/Dashboard.tsx`, `frontend/src/api/dashboard.ts`,
`frontend/src/types/dashboard.ts`, `frontend/src/pages/OPCUAPage.tsx`,
`frontend/src/components/ClickableBookPath.tsx`,
`frontend/src/lib/domain/bookRoles.ts` и хук настроек, если он типизирует
ответ отдельно.

### Диалог «Ввести путь» — список книг

Выбран вариант C из UI-прототипа (ветка `prototype/standby-book-ui`):
**центральная модалка со списком книг**, не выезжающая панель и не два поля.

- Список строк: текущие основная/запасная + последние введённые пути
  (память `lib/domain/recentPaths`, до 3) без дублей.
- В строке: короткая подпись пути (последние два сегмента), полный путь в
  **кликабельном поле** (`components/ClickableBookPath.tsx`): нажатие в любом
  месте включает редактирование, текст выделяется; карандаш и подпись
  «изменить» видны всегда, а не только при наведении.
- Кнопки роли в строке: «Основная» / «Запасная» / «—». Основная ровно одна,
  запасная — не больше одной: назначение роли снимает её с прежней книги.
- «Добавить путь» — поле плюс кнопка; Enter добавляет.
- Вверху — «Читается сейчас» по данным сервера; внизу — итог по запасной.
- «Сохранить» вызывает `POST /dashboard/excel/books`; успех закрывает
  диалог, обновляет данные и запоминает пути. Ошибка показывается в диалоге,
  диалог не закрывается.

### Строка статуса

- Пилюля роли: «Основная <имя>» / «ЗАПАСНАЯ <имя>» / «Запасная не настроена»
  (пунктирная рамка, пока режим выключен). Нажатие открывает диалог.
- Полный путь книги — тоже кнопка с карандашом: нажатие открывает тот же
  диалог.
- При `role === "reserve"` — баннер «Читается запасная книга. Основная не
  пополняется с ЧЧ:ММ» (время из `main_last_growth`), плюс путь основной
  книги. Если времени нет — «нет данных о росте».

### Настройки (OPCUAPage)

- В блоке «Книга учёта» показываются основная, запасная и роль читаемой.

### API-клиент и типы

- `dashboardApi.saveBookRoles(mainPath, reservePath)`.
- `FileStatus`: `role`, `main_file_path`, `reserve_file_path`,
  `main_last_growth`.
- Настройки: `excel_reserve_path`, `excel_role`.
