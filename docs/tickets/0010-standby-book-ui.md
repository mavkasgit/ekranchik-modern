# 0010 — Экран: роли в диалоге пути, метка и баннер

Спека: [0001](../specs/0001-standby-book.md). Решение: [ADR 0009](../adr/0009-standby-book-follows-growing-rows.md).
Зависит от: 0008 (контракт API зафиксирован спекой).

## Задача

Оператор задаёт две книги и видит, какую книгу читает дашборд сейчас.

## Объём

Файлы: `frontend/src/pages/Dashboard.tsx`, `frontend/src/api/dashboard.ts`,
`frontend/src/types/dashboard.ts`, `frontend/src/pages/OPCUAPage.tsx` и хук
настроек, если он типизирует ответ отдельно.

### Диалог «Ввести путь»

- Два поля: «Основная книга» и «Запасная книга (необязательно)». Поле
  основной при открытии заполнено текущей основной (иначе последним введённым
  путём), поле запасной — текущей запасной.
- «Последние пути» — до 3 путей (память уже есть, `lib/domain/recentPaths`);
  у каждого две кнопки-роли «Основная» / «Запасная», клик подставляет путь в
  соответствующее поле. Текущие роли подсвечены.
- «Применить» вызывает `POST /dashboard/excel/books`; успех закрывает диалог и
  обновляет данные дашборда. Пустая запасная — режим выключен.
- Ошибка сервера показывается текстом, диалог не закрывается.

### Строка статуса

- Рядом с именем книги метка роли: «ЗАПАСНАЯ» заметным цветом, «основная»
  спокойным; при выключенном режиме метки нет.

### Баннер

- При `role === "reserve"`: «Читается запасная книга. Основная не пополняется
  с ЧЧ:ММ» (время из `main_last_growth`), плюс путь основной книги.
  Если времени нет — «нет данных о росте».
- Баннер не дублирует существующее предупреждение об устаревании файла.

### Настройки (OPCUAPage)

- В блоке «Книга учёта» показываются основная, запасная и роль читаемой.

### API-клиент и типы

- `dashboardApi.saveBookRoles(mainPath, reservePath)`.
- `FileStatus`: `role`, `main_file_path`, `reserve_file_path`,
  `main_last_growth`.
- Настройки: `excel_reserve_path`, `excel_role`.
