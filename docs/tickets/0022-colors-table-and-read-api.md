# 0022 — Справочник цветов: таблица, засев и чтение

Спека: [0003](../specs/0003-color-dictionary-and-third-party.md).
Блокирует: 0023, 0024, T-381.

## Задача

В Экранчике появляется собственный справочник цветов: код, название, hex,
код операции, время изменения и происхождение. Он засевается текущими
названиями и полным веером ClassicELOX, читается одним API и переживает
перезапуск. Это единственный источник цвета для дашборда и «Всех цветов».

## Объём

### Данные

- Миграция `003_colors`: таблица `colors` с полями
  `id`, `code` (nullable), `name`, `hex`, `operation_code` (nullable, unique),
  `source` (`ktm`/`local`), `updated_at`, `created_at`.
- Модель `Color` и отношение к БД по образцу `Profile`.
- Засев в миграции:
  - десять текущих названий: серебро, черный, золото, шампань, титан,
    бронза, медь, растрав, Rose Gold, Rose Bronze;
  - двенадцать цветов веера: `C0` Серебро, `C35` Чёрный, `S120-0` Золото,
    `S120-2` Старое золото, `C31` Светлая шампань, `C32` Тёмная шампань,
    `C33` Светлая бронза, `C34` Тёмная бронза, `C41` Медь, `C44` Тёмная медь,
    `C51` Нержавеющая сталь, `C54` Тёмный титан;
  - hex для веера — с фото, справочно; у старых названий — текущие значения;
  - `Rose Gold`, `Rose Bronze`, `растрав` получают локальные коды `RG`,
    `RB`, `RST`.
- У старых операций KTM отображаемого кода нет: `code` пустой, `source`
  станет `ktm` после первого синка.

### API

- `GET /api/colors` — весь справочник, стабильный порядок: сначала по коду,
  затем по названию.
- Поля ответа: `id`, `code`, `name`, `hex`, `operation_code`, `source`,
  `updated_at`.
- Пустой справочник — пустой массив, не 404.
- Схема ответа отдельная, чтобы потом можно было добавить поля, не ломая
  клиента.

### Тесты

- Миграция создаёт таблицу и засевает 22 строки; повторный запуск не плодит
  дубли.
- `GET /api/colors` отдаёт коды `C31`, `C32`, `C41`, `C51` и названия.
- У `RG`, `RB`, `RST` есть код, у старого `серебро` кода нет.
- Ответ не содержит служебных полей БД.

## Приёмка

1. После миграции `GET /api/colors` отдаёт 22 цвета.
2. `C32` есть с названием «Тёмная шампань» и непустым hex.
3. `серебро` есть без кода; панель пока для него показывает аббревиатуру.
4. Повторный запуск миграции и синка не создаёт дублей.
