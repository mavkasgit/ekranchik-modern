# 0018 — Просмотр фото: вписано, зум, копирование и скачивание

Спека: [0002](../specs/0002-catalog.md). Предшествует:
[0016](0016-catalog-screen-read-only.md).

## Задача

Любое фото в каталоге открывается целиком по размеру экрана. Зум, панорама,
копирование и скачивание переносятся из ktm2000
(`frontend/src/features/references/components/FullscreenPhoto.tsx` и
`lib/photoTransfer.ts`), но стартовый масштаб там 1:1 — здесь «1×» значит
«вписано».

## Объём

### Математика

Новый `frontend/src/lib/domain/photoViewer.ts`:

- `fitScale(natural, viewport)` — `min(w/nw, h/nh)`, не больше 1 (мелкое фото
  не растягиваем);
- `clampPan({ x, y }, scale, natural, viewport)` — картинка не уезжает за
  пределы окна;
- `zoomAroundPoint(view, pointer, nextZoom)` — зум к курсору/пальцу;
- `zoomFromWheel(delta, zoom)` и границы 1–4×.

`photoViewer.test.ts` — вписано на 1920×1080, 1366×768, 900×500 и 390×844;
зум 1–4×; панорама не выходит за границы; двойной клик возвращает 1×.

### Компонент

Новый `frontend/src/components/PhotoViewer.tsx`:

- оверлей `fixed inset-0`, фон чёрный, картинка по центру, `object-contain`;
- старт — `fitScale`, зум 1–4×, колесо и пинч (pointer events), панорама
  мышью/пальцем, двойной клик — сброс, кнопки «+»/«−»;
- Esc закрывает, кнопка закрытия в углу, `aria-label` у кнопок;
- копирование в буфер: `navigator.clipboard.write`, при HTTP — фолбэк
  `execCommand("copy")` по временному выделению (как в ktm2000);
- скачивание: `fetch` → blob → `<a download>`; имя файла — артикул;
- полноэкранный режим браузера сохраняется (кнопка «Развернуть»);
- кропа и замены фото нет.

`frontend/src/pages/Catalog.tsx` — превью и фото в карточке открывают
`PhotoViewer`; текущий `isFullscreen`-код удаляется вместе с кропом
([0019](0019-remove-catalog-writes.md)).

### E2E

`e2e/tests/catalog.spec.mts` — один сценарий:

1. открыть `/catalog`, дождаться карточек;
2. клик по превью — фото целиком внутри вьюпорта и диалога, пропорции
   сохранены, прокрутки нет (1366×768 и 900×500);
3. колесо — масштаб вырос, картинка не вышла за окно;
4. Esc — оверлей закрыт;
5. клик по «Скачать» — событие `download`.

## Проверка

1. `mise run check`, `mise run test`, `npm run test:e2e` (стенд и Chrome с
   CDP на 9222).
2. Руками: открыть портретное фото на окне 900×500 — видно целиком; зум
   колесом и пинчем на планшете; Esc.
