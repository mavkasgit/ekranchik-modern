# 0026 — Убрать `static/ekranchik.db` из git

Источник: ретро сессии 2026-11-19. Решение владельца: данные dev-стенда не
должны жить в репозитории.

## Задача

Перестать отслеживать `static/ekranchik.db`. Файл остаётся на диске у
разработчика и продолжает использоваться стендом, но git его больше не знает.

## Объём

- `git rm --cached static/ekranchik.db` — файл на диске не удалять.
- Добавить `static/ekranchik.db` в `.gitignore` (рядом с бэкапами
  `static/ekranchik.db.bak-*`).
- В `AGENTS.md` (или в `docs/specs/0002-catalog.md`, где описаны данные
  стенда) зафиксировать: БД dev-стенда — локальные данные, в git не
  хранится; на чистой машине её создают миграции (`alembic upgrade head`,
  засев цветов 003–005), каталог наполняет синк из KTM.
- Не переписывать историю git: старые коммиты с бинарником остаются.

## Приёмка

1. `git ls-files static/ekranchik.db` пуст.
2. Файл есть на диске, `git status` чистый (файл игнорируется).
3. `mise run check` зелёный, backend-тесты зелёные.
4. На чистой БД миграции создают таблицу `colors` и засевают 22 строки
   (проверить существующим тестом/ручной командой).
5. В документации сказано, что БД стенда локальная и не коммитится.

## Ограничения

- Не трогать прод-данные и контейнеры.
- Не запускать синк, который меняет `static/ekranchik.db` (файл и так
  локальный).
- Отдельная ветка от `main`, не смешивать с другими изменениями.
