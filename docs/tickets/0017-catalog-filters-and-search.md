# 0017 — Каталог: поиск, сортировка и фильтры в колонках

Спека: [0002](../specs/0002-catalog.md). Предшествует:
[0016](0016-catalog-screen-read-only.md).

## Задача

Витрина показывает весь список сразу, поэтому поиск, сортировка и фильтры
считаются на клиенте. Сортировка и фильтры живут в заголовках колонок, а не в
отдельной панели диапазонов. Режим, сортировка и фильтры переживают
перезагрузку.

## Объём

### Чистые функции

`frontend/src/lib/domain/tableQuery.ts` — поиск, фильтр и мультисортировка
(до трёх ключей, пустые значения в конце, `localeCompare(..., "ru")` и числа).

`frontend/src/lib/domain/columnFilters.ts` — состояние фильтров (значения,
текст, диапазоны), частичный поиск по списку значений, счётчик и сохранение.

`frontend/src/lib/domain/columnSpecs.ts` — описание колонки: чем фильтруется,
как сортируется и что читает из строки; из него собираются список значений,
предикат строк и читатели сортировки.

`frontend/src/lib/domain/catalogView.ts` — колонки каталога, общий поиск,
конвейер витрины и чтение старых записей `localStorage`.

Тесты: `tableQuery.test.ts`, `columnFilters.test.ts`, `catalogView.test.ts`.

### Экран

`frontend/src/pages/Catalog.tsx`:

- поиск — 200 мс debounce, клиентский; серверный `/catalog?q` не вызывается;
- таблица: сортировка — клик по иконке в заголовке; до трёх столбцов с
  приоритетами, повторный клик меняет направление и снимает ключ; клик по
  подписи открывает поповер фильтра с поиском и списком значений (как в
  ktm2000), у диапазонных колонок — «от/до»;
- плитка: сортировка — дропдауном, фильтры — кнопкой «Фильтры» в тулбаре
  (тот же компонент поповера), активные — чипами со снятием;
- счётчик активных фильтров в тулбаре и кнопка сброса в правом верхнем углу
  таблицы;
- выбранные режим, сортировка и фильтры — в `localStorage` (ключи с
  префиксом каталога, старые значения без новых полей читаются);
- изображения — `loading="lazy"` и `decoding="async"`.

`frontend/src/hooks/useCatalog.ts` — `placeholderData: keepPreviousData` для
списка (при ручном обновлении список не мигает скелетоном).

## Тесты

- `vitest` на `catalogView` — единственный источник правды для фильтрации.
- Ручная проверка: фильтр по длине и «с фото» в таблице, переключение на
  плитку — фильтры на месте, чипы снимаются, «Сбросить» очищает всё.

## Проверка

1. `mise run check`, `mise run test`.
2. 215 артикулов: ввод в поиск не делает сетевых запросов (Network), список
   фильтруется мгновенно.
3. Перезагрузить страницу — режим, сортировка и фильтры сохранились.
