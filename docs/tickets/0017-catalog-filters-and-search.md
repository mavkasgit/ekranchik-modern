# 0017 — Каталог: поиск, сортировка и фильтры в колонках

Спека: [0002](../specs/0002-catalog.md). Предшествует:
[0016](0016-catalog-screen-read-only.md).

## Задача

Витрина показывает весь список сразу, поэтому поиск, сортировка и фильтры
считаются на клиенте. Сортировка и фильтры живут в заголовках колонок, а не в
отдельной панели диапазонов. Режим, сортировка и фильтры переживают
перезагрузку.

## Объём

### Чистые функции

Новый `frontend/src/lib/domain/catalogView.ts`:

- `matchesQuery(profile, query)` — нормализованный поиск по артикулу,
  наименованию и примечанию;
- `CatalogFilters` и `matchesFilters(profile, filters)` — артикул и
  наименование «содержит», количество `from`/`to`, длина (`Set` значений),
  примечание «содержит», `hasPhoto`, `updatedFrom`/`updatedTo`;
- `sortProfiles(list, sort)` — один столбец, `localeCompare(..., "ru")` для
  строк, числа для длины и количества, `null` в конце;
- `lengthOptions(list)` — уникальные длины по возрастанию;
- `activeFilterCount(filters)` — для счётчика.

`frontend/src/lib/domain/catalogView.test.ts` — поиск, каждый фильтр, пустой
фильтр, сортировка с `null` и кириллицей, `lengthOptions`, счётчик.

### Экран

`frontend/src/pages/Catalog.tsx`:

- поиск — 200 мс debounce, клиентский; серверный `/catalog?q` не вызывается;
- таблица: клик по заголовку сортирует (один столбец, повторный клик меняет
  направление), в заголовке — кнопка фильтра с поповером;
- плитка: сортировка — существующим дропдауном, фильтры — кнопкой «Фильтры»
  в тулбаре (тот же компонент поповера), активные — чипами со снятием;
- счётчик активных фильтров и «Сбросить» в тулбаре;
- выбранные режим, сортировка и фильтры — в `localStorage` (ключи с
  префиксом каталога, старые значения без новых полей читаются);
- изображения — `loading="lazy"` и `decoding="async"`.

`frontend/src/hooks/useCatalog.ts` — `placeholderData: keepPreviousData` для
списка (при ручном обновлении список не мигает скелетоном).

## Тесты

- `vitest` на `catalogView` — единственный источник правды для фильтрации.
- Ручная проверка: фильтр по длине и «с фото» в таблице, переключение на
  плитку — фильтры на месте, чипы снимаются, «Сбросить» очищает всё.

## Проверка

1. `mise run check`, `mise run test`.
2. 215 артикулов: ввод в поиск не делает сетевых запросов (Network), список
   фильтруется мгновенно.
3. Перезагрузить страницу — режим, сортировка и фильтры сохранились.
