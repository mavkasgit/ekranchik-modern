# 0016 — Экран каталога: витрина и примечание

Спека: [0002](../specs/0002-catalog.md). Предшествует:
[0015](0015-catalog-api-read-only.md).

## Задача

Переписать экран каталога под витрину: артикул, наименование, длина,
количество и фото только читаются; редактируется одно примечание. Убрать
создание, правку, удаление, загрузку и кроп фото, ZIP. Ввести термины
«Артикул», «Наименование», «Примечания» и убрать любые упоминания источника
данных.

## Объём

### Типы и API-клиент

`frontend/src/types/profile.ts` — `description: string | null`, убрать
`usage_count` из `Profile`; `ProfileSearchResult` не трогать.

`frontend/src/api/catalog.ts` — оставить `getAll`, `getProfile`, добавить
`updateNotes(id, notes)`; удалить `createOrUpdate`, `update`, `delete`,
`uploadPhoto`, `updateThumbnail`, `deleteFullPhoto`, `deleteThumbnail`.
`search` остаётся (используется API, не экраном).

`frontend/src/hooks/useCatalog.ts` — мутация `useUpdateNotes` с
оптимистичным обновлением и откатом по ошибке; инвалидация `catalogKeys`.

### Экран

`frontend/src/pages/Catalog.tsx` — после выпила (тикет 0019) остаётся
витрина:

- заголовок «Каталог артикулов», счётчик «N артикулов»;
- плитка: превью, артикул, наименование, бейджи «N шт/подв» и «N мм»,
  примечание в две строки; без кнопок правки/удаления; без FAB «+»;
- таблица: фото, артикул, наименование, количество, длина, примечания,
  «Изменён»; без колонки действий;
- диалог артикула: поля — текст (`<dl>`), не `disabled`-инпуты; примечание —
  textarea, автосохранение по `blur`, тосты «Сохранено» / «Не удалось
  сохранить»; без кнопки «Сохранить»;
- на ширине < 768 px диалог на весь экран: фото сверху, примечание снизу;
- пустые состояния: «Каталог пуст» и «Ничего не найдено» — без подсказок о
  синке и источнике;
- текст интерфейса не содержит «KTM», «синхронизация», «источник»,
  «обновлено из» и дат обновления.

### Примечание

`PATCH /catalog/{id}/notes`; пустой текст отправляется как `null`. Пока идёт
запрос — поле остаётся редактируемым, повторный blur не плодит дубли
(мутация по `id` + последний текст). Ошибка возвращает прежнее значение и
показывает тост.

## Тесты

- `tsc`, `oxlint`, `oxfmt`; `vitest` для хелпера сборки тела
  `{ notes }` (пустая строка → `null`).
- Ручная проверка: карточка без кнопок правки, примечание переживает
  перезагрузку, поля не редактируются.

## Проверка

1. `mise run check`, `mise run test`.
2. Стенд: изменить примечание, перезагрузить страницу — значение на месте;
   `GET /catalog/{name}` его отдаёт.
3. Проверить 1366×768 и 390×844: диалог не обрезан, фото и примечание видны.
