# Строка Подвеса рождается у producer'а, ключи остаются историческими

Строку Подвеса собирает ровно один producer — `ExcelService._process_dataframe` —
и она объявлена типом `HangerRow` (`app/services/hanger_row.py`), а не набором
словарных ключей, которые каждый потребитель угадывает. Тот же тип читают правила
матчинга (`app.services.matching`) и метаданные подвеса OPC UA; маппинг в ответ
API — один, `to_hanger_data`.

Рассматривали переименование ключей в доменные (`kpz`, `lamels`) и замену пустого
значения «—» на `None`. Отказались: ключи — это контракт с фронтендом, websocket и
e2e (переименование — отдельное решение со своей миграцией, а не побочный эффект
объявления формы), а «—» уже язык правил матчинга (`matching._EMPTY_TIME_TOKENS`).
Сентинел вынесен в константу `EMPTY`, чтобы его не сравнивали с литералом.
