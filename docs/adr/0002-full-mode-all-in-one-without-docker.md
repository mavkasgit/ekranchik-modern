# Полный режим: All-in-One EXE без Docker

На заводской машине нужен режим, где бэкенд, веб-интерфейс и экран киоска работают на одном компьютере без Docker. Решение (issue #9): **одно приложение** `EkranchikAllInOne.exe`, которое в одном процессе:

1. Запускает бэкенд как `python.exe -m uvicorn` из **embedded Python 3.12 + pre-built site-packages**, лежащих рядом с exe (не PyInstaller — обновление кода = копирование файлов, без пересборки бинарника). Дочерний python назначен в Job Object — при аварийной смерти приложения не остаётся висеть.
2. Бэкенд **сам раздаёт SPA-сборку `dist/` и статику** на порту 8083 — на целевой машине нет ни nginx, ни Node, ни второго процесса-сервера.
3. После готовности сервера **сам открывает экран киоска** — WebView2-окно `KioskForm` в том же процессе с URL `http://localhost:8083`. Отдельного процесса киоска нет: в трее одна иконка, приложение для пользователя одно. Esc/«Свернуть»/Alt+F4 прячет экран в трей, сервер продолжает работать; возврат — клик по иконке трея или кнопка «Показать экран» в настройках.
4. Данные (SQLite БД + images) живут в `%LOCALAPPDATA%\Ekranchik\data` — переживают переустановку/обновление программы. Разовый перенос данных с текущего Docker-прода делается вручную (копирование файла БД и images), дальше машина самодостаточна.

Дистрибуция: **один** `EkranchikSetup.exe` (Inno Setup) с двумя типами установки — «Только киоск» (самостоятельный `Ekranchik.exe` для машин-экранов, показывающих чужой URL) и «Полный пакет» (одно приложение выше); повторный запуск меняет тип. Единое окно настроек используется обоими режимами: в полном — Excel, OPC UA, симуляция, монитор, автозапуск, логи, обновления; в киоске — сокращённо (URL, монитор, автозапуск, обновления). Проверка/установка обновлений — только в окне настроек (пункта в меню трея нет); киоск дополнительно показывает баннер на дашборде. Меню трея обоих режимов: «Переключить монитор», «Режим простоя», «Настройки», «Выход».

Код киоска (`KioskForm`, `ConfigManager`, единое окно настроек) вынесен в общие файлы и компилируется в оба exe; во встроенном режиме `KioskForm` работает с флагом `hosted` — без собственного трея, без баннера обновлений (наружу на дашборде ничего не показывается), `Esc` прячет окно. Обновления полного режима — через установщик (канал `full-v`, ассет `EkranchikSetup.exe`), киоска — как раньше (канал `v`, самозамена `Ekranchik.exe`). При первом старте полного приложения старое Run-значение автозапуска киоска `Ekranchik` удаляется (миграция).

## Considered Options

- **PyInstaller-сборка бэкенда в exe** — отклонено: капризно с FastAPI/alembic/OPC UA, тяжёлые обновления.
- **Отдельный статик-сервер (nginx/Node) рядом** — отклонено: лишний процесс и зависимость на целевой машине.
- **All-in-One запускает киоск отдельным процессом** (первоначальная версия, заменена issue #9): две одинаковые иконки в трее, «два приложения» в глазах пользователя, падение UI киоска оставалось для сервера невидимым.
- **Встроить киоск-окно в All-in-One без выноса кода в общий файл** — отклонено: дублирование кода киоска; вместо этого киоск-логика собрана в общих файлах, компилируемых в оба exe.
